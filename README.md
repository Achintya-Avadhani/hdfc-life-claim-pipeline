# HDFC Life Claim Pipeline

A plain Java console application demonstrating data structures, algorithms, exception handling, and multithreading using HDFC Life claim data.

## Seed Data

25000, 18000, 42000, 15000, 31000, 9000

Total Claim Amount: 140000

## Concepts Covered

- Singly Linked List
- Iterative & Recursive Reversal
- Floyd's Cycle Detection
- Add Two Numbers using Linked Lists
- Array & Linked Stack
- Parentheses Checker
- Postfix Evaluation
- Circular Queue
- BFS Graph Traversal
- PriorityQueue
- Multithreading
- Custom Exceptions

## Complexity

| Algorithm | Time | Space |
|---|---|---|
| Linked List Insert/Delete | O(n) | O(1) |
| Reverse Iterative | O(n) | O(1) |
| Reverse Recursive | O(n) | O(n) |
| Cycle Detection | O(n) | O(1) |
| Add Two Numbers | O(max(m,n)) | O(max(m,n)) |
| Stack Push/Pop | O(1) | O(1) |
| Circular Queue | O(1) | O(1) |
| BFS | O(V + E) | O(V) |
